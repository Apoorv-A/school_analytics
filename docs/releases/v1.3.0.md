## Summary

This release completes the Phase 2 ERP operations slice: scheduled and webhook ingest with per-tenant signing secrets, bundle fingerprint delta sync, and conflict resolution when ERP data disagrees with analytics-owned rows. Principals can review and resolve conflicts from **Admin → Data import** or the conflict API.

## Changes

### User-visible features

- **Import conflict resolution** — Pending disagreements on scores, remarks, and attendance when ERP sync/webhook ingest would overwrite `source_system=analytics` rows. Admin UI at `/admin/import` with keep local, accept ERP, and per-field merge.
- **Conflict and import APIs** — `GET /api/import/conflicts` and `POST /api/import/conflicts/{id}/resolve` (admin + `bulkImport` only) with security audit events.
- **ERP webhook ingest** — `POST /api/erp/import` with HMAC-signed multipart bundles (`scripts/erp_webhook_smoke.py`).
- **Connector sync** — SFTP pull and REST polling via `python -m app.import_.connectors.cli sync`; local drop-directory sync for cron-style jobs.
- **Delta sync** — Skip re-apply when bundle SHA-256 matches last successful sync for the tenant/channel (`--force` override).
- **Import run history** — `import_runs` audit for CLI, admin upload, API, webhook, and connector paths.

### Internal / ops improvements

- Ops runbooks: [erp-import-conflicts-smoke.md](../operations/erp-import-conflicts-smoke.md), [erp-delta-sync.md](../operations/erp-delta-sync.md), [erp-connector-sync.md](../operations/erp-connector-sync.md).
- **Demo seeder** — `scripts/seed_import_conflict_demo.py` for one-click local conflict on Sunrise SQLite.
- Regression: `tests/test_import_conflicts.py`, `tests/test_import_delta.py`, `tests/test_connectors.py`, `tests/test_erp_webhook.py`.

## Breaking changes

None for existing portal users. Operators enabling ERP webhook ingest must supply per-tenant secret refs (no global webhook secret).
